# frontend 文件来源、作用、依赖与影响说明（2026-05-05）

- 目录：`E:\trae_project\AI-FIT\frontend`
- 说明：本文档按当前重构后的目录记录，不再描述已退役的 `src/lib/pose/*`、`src/lib/food/*`、`src/pages/poseTool/*`。

## 1. 根目录

| 路径 | 来源 | 作用 | 改动影响 |
|---|---|---|---|
| `src/` | 手写维护 | React/Vite 业务源码 | 删除会导致前端不可用 |
| `public/` | 手写维护/静态资源 | 图片、模型、字体、主题 CSS | 误删会导致资源 404 或 Pose 模型加载失败 |
| `node_modules/` | npm 下载 | 本地依赖 | 可删除后重装 |
| `dist/` | Vite 构建产物 | 部署产物 | 可删除后重建 |
| `index.html` | 手写维护 | SPA HTML 入口 | 改错会导致应用无法加载 |
| `package.json` | 手写维护 | 脚本与依赖声明 | 改动影响安装、构建、校验 |
| `package-lock.json` | npm 生成 | 精确依赖锁定 | 删除会导致依赖解析漂移 |
| `vite.config.ts` | 手写维护 | Vite 构建和开发配置 | 改动影响 dev/build |
| `tsconfig*.json` | 手写维护 | TypeScript 编译配置 | 改动影响类型检查与构建 |

## 2. 应用入口

| 文件 | 来源 | 作用 | 依赖与影响 |
|---|---|---|---|
| `src/main.tsx` | 手写维护 | 挂载 React、注入 Router 与全局样式 | 全站入口，不可删 |
| `src/App.tsx` | 手写维护 | 路由表、鉴权守卫、页面懒加载 | 影响所有页面可达性 |
| `src/vite-env.d.ts` | 模板后维护 | Vite 类型声明 | 影响 TS 编译 |

| 目录 | 作用 | 上游依赖 | 下游依赖 |
|---|---|---|---|
| `src/pages/public/` | 首页、关于页、404 | `App.tsx` | layout、public 资源 |
| `src/pages/auth/` | 登录、注册、重置密码 | `App.tsx` | `modules/user`、`state/auth-context` |
| `src/pages/blog/` | 博客列表与详情 | `App.tsx` | `modules/blog`、layout 组件 |
| `src/pages/food/` | 食物识别与餐食记录 | `App.tsx` | `modules/food`、通用 API |
| `src/pages/pose/` | Pose 训练、报告、历史 | `App.tsx` | `modules/pose`、`components/pose` |
| `src/pages/user/` | 用户资料与隐私 | `App.tsx` | `modules/user` |
| `src/pages/admin/` | 管理后台 | `App.tsx` | 管理 API |

## 5. `lib/` 基础设施

`lib/` 的定位是跨业务复用，不再承载单一业务域。

| 文件 | 来源 | 作用 | 被谁依赖 |
|---|---|---|---|
| `src/lib/api.ts` | 手写维护 | 通用 `apiFetch`、上传封装 | 各业务模块 API |
| `src/lib/auth.ts` | 手写维护 | token/session 客户端能力 | 登录态与用户模块 |
| `src/lib/media.ts` | 手写维护 | 通用媒体工具 | 需要媒体处理的页面/模块 |
| `src/lib/report/print.ts` | 手写维护 | 报告打印能力 | 报告页面 |
| `src/lib/report/unified.ts` | 手写维护 | 报告归一化 | Pose reporting 与归档 |

业务代码放入 `modules/`，不要回迁到 `lib/`。

## 7. Pose 内部分层

| 目录 | 作用 | 改动影响 |
|---|---|---|
| `modules/pose/api.ts` | Pose 后端 API 客户端 | 影响 policy/training/report 请求 |
| `modules/pose/policy.ts` | policy 获取、默认规则、tuning 转换 | 影响四动作阈值与运行策略 |
| `modules/pose/domain/` | 动作定义与命名 | 影响路由动作解析与展示 |
| `modules/pose/vision/` | MoveNet、实时 provider、绘制与底层 tracker | 影响姿态检测和 overlay |
| `modules/pose/analyzer/` | 四动作分析器和共享反馈类型 | 影响动作判定、计数、问题识别 |
| `modules/pose/runtime/live.ts` | 实时训练主入口 | 影响 live start/stop/reset/save/report |
| `modules/pose/runtime/offline.ts` | 离线视频主入口 | 影响文件选择、分析、回放、归档 |
| `modules/pose/runtime/live/*` | live runtime 私有 helper | 不对页面公开 |
| `modules/pose/runtime/offline/*` | offline runtime 私有 helper | 不对页面公开 |
| `modules/pose/reporting/` | 报告模型、归档、policy stamp、overlay replay | 影响报告生成和训练历史 |
| `modules/pose/helpers/` | Pose 私有报告生成、建议映射、policy rules | 影响报告质量与文案 |

## 9. 当前工程约束

- 页面层不得直接 import `modules/pose/vision/*`、`modules/pose/analyzer/*`。
- 业务域代码不得新增到 `src/lib/`。
- 新页面必须放入 `src/pages/<domain>/`。
- 新后端路由应放入 `backend/app/routes/<domain>/` 并在 `backend/app/__init__.py` 注册。
