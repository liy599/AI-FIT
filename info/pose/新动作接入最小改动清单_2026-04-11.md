# 新动作接入最小改动清单（最终版，实时 Analyzer 插件化）

日期：2026-04-11

## 0. 总原则

新动作接入实时分析必须与深蹲范式一致，禁止“只加文案不加 Analyzer”。新增动作以“可复用框架”为默认目标：门控、issue→建议映射、报告拼装走共享层，动作只承载“特征提取 + 规则判定 + 状态机计次”。

## 1. 必做改动

1. [exercises.ts](file:///Users/zjl/Desktop/Study/Program/4-2/TRAE/AI-FIT/frontend/src/lib/pose/exercises.ts) 新增动作配置（slug/标题/指标文案）。  
2. 新建 `frontend/src/lib/pose/realtime<YourAction>.ts` 专用 Analyzer（参考 [realtimeSquat.ts](file:///Users/zjl/Desktop/Study/Program/4-2/TRAE/AI-FIT/frontend/src/lib/pose/realtimeSquat.ts)）。  
3. 在 [registry.ts](file:///Users/zjl/Desktop/Study/Program/4-2/TRAE/AI-FIT/frontend/src/lib/pose/analyzer/registry.ts) 的 `createAnalyzer()` 注册新动作。  
4. 在 Analyzer 内实现统一接口：`analyzeFrame({ landmarks, gatePaused }) / resetSession() / setMode?(mode)`。  
5. 需要动作专属建议时，在 [issues.ts](file:///Users/zjl/Desktop/Study/Program/4-2/TRAE/AI-FIT/frontend/src/lib/pose/analyzer/issues.ts) 的 `mapSuggestionFromIssue()` 增加分支。  
6. 需要动作专属“范围/阶段达成”提示时，在 [liveHelpers.ts](file:///Users/zjl/Desktop/Study/Program/4-2/TRAE/AI-FIT/frontend/src/lib/pose/analyzer/liveHelpers.ts) 的 `evaluateRangeCheck()` 增加分支。  
7. 保证输出与 `RealtimeFeedback` 语义一致（null 策略、warnings/issues、session 统计、lastRep* 字段）。

1. 实现 `build<YourAction>AlignedReport()`（参考 [squatReport.ts](file:///Users/zjl/Desktop/Study/Program/4-2/TRAE/AI-FIT/frontend/src/lib/pose/analyzer/squatReport.ts) 的结构与 contract）。  
2. 实现 `build<YourAction>VideoLiveStyleReport()`：离线逐帧回放同一个 Analyzer，产出对齐版报告。

## 3. 验收标准

1. 实时可稳定计次。  
2. 可给出动作专用 issues/warnings。  
3. `correct/incorrect` 与 session 统计正确。  
4. 页面显示指标与动作语义一致。  
5. `npm run typecheck` 通过。

## 4. 禁止项

1. 禁止直接复用其他动作阈值上线。  
2. 禁止仅使用通用提示而无动作规则。  
3. 禁止 Analyzer 输出字段与既有语义不兼容。
