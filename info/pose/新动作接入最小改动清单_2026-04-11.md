# 新动作接入最小改动清单（实时分析）

日期：2026-04-11

## 0. 总原则

新动作接入实时分析必须与深蹲范式一致，禁止“只加文案不加 Analyzer”。

## 1. 必做改动

1. `exercises.ts` 新增动作配置（slug/标题/指标文案）。  
2. 新建 `realtime<YourAction>.ts` 专用 Analyzer。  
3. 在 `poseToolHelpers.ts` 的 `createAnalyzer()` 注册新动作。  
4. 在 `evaluateRangeCheck()` 和建议映射补动作分支。  
5. 保证输出与 `RealtimeFeedback` 字段语义一致。

## 2. 验收标准

1. 实时可稳定计次。  
2. 可给出动作专用 issues/warnings。  
3. `correct/incorrect` 与 session 统计正确。  
4. 页面显示指标与动作语义一致。  
5. `npm run typecheck` 通过。

## 3. 禁止项

1. 禁止直接复用其他动作阈值上线。  
2. 禁止仅使用通用提示而无动作规则。  
3. 禁止 Analyzer 输出字段与既有语义不兼容。
