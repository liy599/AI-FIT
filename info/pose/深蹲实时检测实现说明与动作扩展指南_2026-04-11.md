# 深蹲实时检测实现说明与动作扩展指南

日期：2026-04-11

## 1. 核心原则

1. 实时检测以动作专用 Analyzer 为核心。  
2. 页面只做流程编排，不承载动作判定细节。  
3. 新动作必须复用深蹲这套“状态机 + 规则判定 + 会话聚合”范式。

## 2. 当前实时链路

1. `PoseToolPage.startLive()` 启动摄像头和逐帧循环。  
2. 每帧调用 `provider.detect()` 获取 landmarks。  
3. 调用 `analyzer.analyze()` 得到 `RealtimeFeedback`。  
4. 更新 UI（rep、accuracy、angles、issues、suggestions）。  
5. 累计会话统计（问题频率、tracking 质量、timeline）。  
6. 会话结束后生成 summary/report 并可归档训练记录。

## 3. 深蹲 Analyzer 的通用价值

`realtimeSquat.ts` 已完整覆盖：

1. 特征提取：膝角、髋角、躯干角、偏移角、跟踪质量。  
2. 状态机计次：`s1/s2/s3` + 回差防抖。  
3. 质量门控：低质量时仅计次或未评估。  
4. 规则判定：膝过脚尖、躯干前倾等。  
5. 会话统计：correct/incorrect/unassessed、节奏、准确率。

这套结构应作为所有新动作的标准模板。

## 4. 新动作实时实现模板（强制）

每个新动作必须有：

1. `realtime<YourAction>.ts` 专用 Analyzer。  
2. `analyze()/resetSession()/detectState()/updateState()`。  
3. 至少 2 条动作专用规则（幅度阈值 + 持续帧阈值）。  
4. 与 `RealtimeFeedback` 一致的输出语义。

## 6. 一句话总结

实时检测标准流程是：

“逐帧姿态检测 -> 动作专用 Analyzer 判定 -> 会话统计聚合 -> 统一反馈与报告”。
