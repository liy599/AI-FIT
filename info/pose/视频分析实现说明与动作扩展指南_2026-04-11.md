# 视频分析实现说明与动作扩展指南（强制复用实时分析器版）

日期：2026-04-11

## 1. 强约束

1. 视频分析必须复用对应实时 Analyzer。  
2. 每个动作必须有专用离线重放分析函数。  
3. 每个动作必须有专用报告生成函数。  
4. 禁止通用占位分析上线。

## 2. 当前实现现状

1. 深蹲已实现“离线重放实时 Analyzer + 专用报告”。  
2. 非深蹲动作目前离线分析已被代码显式禁用，等待专用实现。

## 3. 标准实现流程（每个动作都一样）

1. 上传视频 + 创建 task。  
2. 抽取逐帧 landmarks。  
3. 调用 `build<Action>VideoLiveStyleReport()`：
- 初始化 `Realtime<Action>Analyzer`
- 逐帧 `analyze()`
- 累计 messageFreq/tracking/timeline
4. 调用 `build<Action>AlignedReport()` 生成动作专用报告。  
5. 回写 task、展示报告、保存训练记录。

## 4. 命名规范

- `build<Action>VideoLiveStyleReport()`
- `build<Action>AlignedReport()`

示例：

- `buildPushupVideoLiveStyleReport()` + `buildPushupAlignedReport()`
- `buildPullupVideoLiveStyleReport()` + `buildPullupAlignedReport()`

## 5. 禁止项

1. 禁止 `analyzeGenericMotion()` 作为新动作离线实现。  
2. 禁止仅用通用报告替代动作专用报告。  
3. 禁止离线与实时使用不同规则口径。
