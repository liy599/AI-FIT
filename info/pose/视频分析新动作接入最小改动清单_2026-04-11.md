# 视频分析新动作接入最小改动清单（强制专用分析版）

日期：2026-04-11

## 0. 总原则

1. 必须复用对应实时 Analyzer。  
2. 必须有动作专用离线重放函数。  
3. 必须有动作专用报告函数。  
4. 不允许走通用占位分支。

## 1. 必做改动（按顺序）

1. `exercises.ts` 增加动作配置。  
2. 若缺失则先实现 `realtime<YourAction>.ts`。  
3. 在 `poseToolHelpers.ts` 新增：
- `build<YourAction>VideoLiveStyleReport()`
- `build<YourAction>AlignedReport()`
4. 在 `PoseToolPage.tsx` 的 `runOfflineAnalysis()` 接入专用分支。  
5. 保证 task 回写与训练归档链路可用。

## 2. 验收门槛

1. 离线分析进入专用重放函数。  
2. 报告包含动作专用指标和建议。  
3. 与实时同动作同样本，关键结论一致。  
4. `npm run typecheck` 通过。

## 3. 禁止项

1. 禁止接入 `analyzeGenericMotion()` 作为新动作实现。  
2. 禁止只输出通用报告。  
3. 禁止离线/实时规则不一致。

## 4. PR 必须包含

1. 专用实时 Analyzer（若原先不存在）。  
2. 专用离线重放函数。  
3. 专用报告函数。  
4. 页面离线分支接入。  
5. 文档更新。
